# 7. 真机推理与安全评估

策略推理会直接控制从臂，必须在完成机械安全检查、相机身份检查和 checkpoint 校验后运行。每次运行应固定记录：checkpoint、颜色任务、场景与光照、episode 编号、终态截图或视频、失败类型和是否为独立复位。

本项目的首轮结果表明，最佳候选是绿色 10k checkpoint 的连续 9/10；它只应作为下一轮独立复验对象。紫色 10k 与 20k 均为 5/10，尚不具备部署依据。

已执行命令与参数记录见 [推理和评估命令](./07-inference-and-evaluation-commands.md)，统计和证据边界见 [真实评估总报告](./09-real-world-evaluation.md)。
