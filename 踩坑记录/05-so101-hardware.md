# 5. SO-101 串口、校准与主从联动

设备编号会因重插改变，因此使用 udev 规则创建 `/dev/ttySO101_LEADER` 和 `/dev/ttySO101_FOLLOWER`。每次运行前确认符号链接、读写权限和对应校准文件。

校准或联动异常时，按以下顺序排查：设备身份 -> serial 权限 -> leader/follower ID -> 校准文件 -> 无相机遥操作 -> 相机。不要在相机报错时同时重校准机械臂，否则无法定位故障来源。

详细序列号、规则和已通过的联动测试见 [硬件测试报告](../项目流程/02-hardware-verification.md)。
